# NachweisCheck Pro — applying your license (EN)

1. Open **NachweisCheck → Settings → License**.
2. Paste the full `NWC2.` key from your license email (line breaks are fine) and choose **Save license**.
3. The panel shows the status badge, *Valid until*, and used/available **mobile seats**.

While the license is valid, all Pro features unlock: multiple active projects, all funder template packs, e-invoice import (ZUGFeRD/XRechnung), the timesheet sign-off chain, auditor seats, and mobile companion seats.

- **Renew / upgrade:** ask sales for a new key and paste it — it replaces the stored one (applied transactionally under an exclusive lock).
- **After expiry:** Pro mutations stop (`LICENSE_REQUIRED`); all data stays readable — nothing is deleted.
- **Removing the license** frees all mobile seats immediately; project data is untouched.
- **Seat downgrade:** when a new key allows fewer mobile seats, surplus seats stay assigned but lose mobile access until seats are freed or the license is upgraded (ranked by assignment date).
