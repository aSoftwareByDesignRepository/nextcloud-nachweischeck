# NachweisCheck Pro — Lizenz einrichten (DE)

1. Öffnen Sie **NachweisCheck → Einstellungen → Lizenz**.
2. Fügen Sie den vollständigen `NWC2.`-Schlüssel aus Ihrer Lizenz-E-Mail ein (Zeilenumbrüche sind egal) und wählen Sie **Lizenz speichern**.
3. Die Karte zeigt Status, *Gültig bis* und genutzte/verfügbare **mobile Plätze**.

Solange die Lizenz gültig ist, sind alle Pro-Funktionen aktiv: mehrere aktive Projekte, alle Geber-Template-Pakete, E-Rechnung-Import (ZUGFeRD/XRechnung), Stundenzettel-Freigabekette, Auditor-Plätze und mobile Companion-Plätze.

- **Verlängern / Upgrade:** neuen Schlüssel anfordern und einfügen — er ersetzt den gespeicherten (transaktional, exklusiv gesperrt).
- **Nach Ablauf:** Pro-Schreibzugriffe stoppen (`LICENSE_REQUIRED`); alle Daten bleiben lesbar — nichts wird gelöscht.
- **Lizenz entfernen** gibt sofort alle mobilen Plätze frei; Projektdaten bleiben unberührt.
- **Downgrade:** Erlaubt ein neuer Schlüssel weniger Plätze, bleiben überschüssige zugewiesen, verlieren aber den mobilen Zugriff, bis Plätze freigegeben oder die Lizenz erweitert wird (Rangfolge nach Zuweisungsdatum).
